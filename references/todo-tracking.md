# 待办与跟踪规范

待办是纪要里唯一会**持续变化**的部分。所以它要有稳定 ID、明确的人、可判断的验收，并且能被增量更新而不破坏原文。

---

## 一、字段

| 字段 | 必填 | 规则 |
|---|---|---|
| `ID` | 是 | `T1` `T2` … 全文唯一，**一旦分配永不重用、永不重排**。删掉的任务保留行、状态改 ⚪ 已取消 |
| `待办事项` | 是 | 动词开头，一句话说清"做什么"。"跟进一下"这类不算 |
| `负责人` | 是 | 原文明确点名的人。写姓名；只有角色时写"王工（硬件）" |
| `跟踪人` | 是 | 负责催办与状态更新的人。**默认 = 负责人**；原文明确有人"盯着/催着/跟进"时填该人 |
| `截止 / 验收` | 是 | 有日期写日期（`11-15`）；无日期写触发条件（"模具到厂后 3 天内"） |
| `状态` | 是 | 见状态机 |
| `下一步` | 否 | 阻塞或进行中时写"等谁 / 缺什么"，帮跟踪人判断卡点 |

三要素缺一不进表：**人 + 动作 + 可验收结果**。缺任何一条 → 进纪要第 7 节"待确认事项"。

---

## 二、状态机

```
⬜ 待启动 ──▶ 🟡 进行中 ──▶ ✅ 已完成
                │  ▲
                ▼  │
              🔴 阻塞
                
⚪ 已取消（任意状态可达）
```

| 状态 | 标记 | 颜色（SVG） | 判定 |
|---|---|---|---|
| 待启动 | ⬜ | `#8F959E` | 还没人动手 |
| 进行中 | 🟡 | `#E8A33D` | 有人在做，有进展 |
| 阻塞 | 🔴 | `#D64545` | 卡在外部依赖，**必须在"下一步"写清卡在哪** |
| 已完成 | ✅ | `#2F9E44` | 有可指认的产出（文件、结论、上线记录） |
| 已取消 | ⚪ | `#8F959E` | 明确不做，理由写进跟进记录 |

不允许的状态写法：`进行中（大概率完成了）`、`基本完成`、`待定`。状态只有这五个。

---

## 三、按人汇总

跟踪视角的核心：**谁说他要盯哪些事**。每次更新状态后重算这张表。

| 负责人 | 待办数 | 进行中 | 阻塞 | 最近截止 |
|---|---|---|---|---|
| 王磊 | 2 | 1 | 0 | 11-15 |
| 陈昊 | 1 | 0 | 1 | 12-05 |

规则：

- 只统计未完成（⬜/🟡/🔴）的条数；✅ 与 ⚪ 不计入"待办数"。
- 一人多活时，最后一个个人跟进节点写"最近截止"。
- 同一人既是负责人又是别人的跟踪人，两处都出现，不合并角色。

---

## 四、跟进记录

位于待办表之后，**倒序**追加，每次更新在顶部加一行：

```markdown
- **2026-11-18** T2 模具 T2 件比计划晚 3 天到厂，状态 待启动 → 阻塞，跟踪人改为李婷。
- **2026-11-12** 初次整理，建 3 条待办。
```

写清：动了哪条 ID、改成什么、为什么。不要写"更新了待办状态"这种无信息量的话。

---

## 五、增量更新协议

用户在会说"王磊那个排产计划出来了"、"T3 推到 12 月 10 号"、"新加一条：让采购问下认证周期"。

**不要重新生成整份纪要。**按下表操作：

| 用户意图 | 只改这些 |
|---|---|
| 某条完成 | 该行 `状态` → ✅、`下一步` 清空；跟进记录加一行 |
| 某条延期 | 该行 `截止 / 验收`；跟进记录加一行（写原截止与新截止） |
| 某条阻塞 | `状态` → 🔴，`下一步` 写清卡点；跟进记录加一行 |
| 新加待办 | 追加行，ID 取当前最大值 +1；跟进记录加一行 |
| 换负责人 | 该行 `负责人`（同时重算"按人汇总"）；跟进记录加一行 |
| 取消 | `状态` → ⚪，理由进跟进记录 |

更新后必须同步三处：**md 待办表 → md 按人汇总 → SVG 待办条**。三者 ID 与状态必须一致，这是自检清单里的硬项。

正文（第 1–5 节）在增量更新时**保持原样**。如果新信息推翻了原结论，不要偷偷改正文：在跟进记录里写明"结论修正建议"，让用户决定。

---

## 六、和看板的关系

SVG 待办条只放 **3–5 条**，选取优先级：

1. 🔴 阻塞的（全部放）
2. 截止日期最近的
3. 负责人是会议主持/业主方的

放不下的留在 md 里。看板底部页脚要写明"全量待办见 XXX_纪要.md"，避免读者以为只有这几条。

每条看板待办 = ID + 事项（≤ 40 字）+ 负责人 + 状态 + 截止，与表格逐字对应。
